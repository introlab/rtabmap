Detailed Description

Statistics and diagnostics returned by Registration.

Filled by RegistrationVis and/or RegistrationIcp during Registration::computeTransformation(). The 6×6 covariance matrix is clamped to Registration::COVARIANCE_LINEAR_EPSILON and Registration::COVARIANCE_ANGULAR_EPSILON on the diagonal when empty or too small.

Visual fields are set by RegistrationVis; ICP fields by RegistrationIcp. In a combined Vis+ICP pipeline, both sets may be populated in the same object.
