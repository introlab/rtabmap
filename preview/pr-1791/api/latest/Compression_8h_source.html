97/*
98 * Compressed depth image layouts (all values little-endian). They are stable: they are
99 * saved in databases, and rtabmap_ros converts them to and from ROS's
100 * compressed_depth_image_transport messages without decompressing the images.
101 *
102 * - ".png": a standard PNG file. 16UC1 depth images are 16 bits grayscale PNGs,
103 * 32FC1 depth images (legacy) are 4-channel 8 bits PNGs holding the float bytes.
104 * - ".rvl" (16UC1):
105 * [0..7] "DEPTHRVL"
106 * [8..11] uint32 cols
107 * [12..15] uint32 rows
108 * [16..] RVL data (see RvlCodec)
109 * - ".png:<maxDepth>:<quantization>" or ".rvl:<maxDepth>:<quantization>" (32FC1):
110 * [0..7] "DEPTHINV"
111 * [8..11] float depthQuantA = quantization*(quantization+1)
112 * [12..15] float depthQuantB = 1 - depthQuantA/maxDepth
113 * [16..] the 16UC1 inverse depth image in ".png" or ".rvl" layout above, where
114 * 0 is invalid and v>0 is the depth depthQuantA/(v-depthQuantB).
115 */
