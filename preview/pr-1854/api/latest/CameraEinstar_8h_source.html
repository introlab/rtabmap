96 // Scanner lighting (see einstar::ScanSettings), live only: IR speckle
97 // projector and white texture LED luminance (strobe routes 0 and 1), laser
98 // brightness (%) and IR camera gain. EXStar turns the texture LEDs off when
99 // scanning without texture and drives the projector harder (observed:
100 // projector 3000, LEDs 0, laser 60, gain 100).
101 void setLighting(int projectorLuminance, int textureLuminance, int laserPercent, int irGain);
102 // IR exposure (us). With autoExposure, it is the starting value and
103 // einstar::AutoExposure keeps the bright end (99th percentile) of the IR
104 // images near aeTarget (0-255); without, it stays fixed. EXStar lets a few
105 // percent of the speckle saturate, which gave more depth on hardware.
106 void setExposure(bool autoExposure, int irExposureUs, double aeTarget);
